
# Saiya Shah — Project Case Studies

Computational Biology + Data Science Engineering, UCLA. Two machine learning course projects below — full write-ups are linked as PDFs in the repo; this page is just an index.


## 1. Domain-Invariant Decoding for Speech Brain-Computer Interfaces
*Co-authored with Yihe Xu and Injun Choi — UCLA ECE C143A/C243A*

Improved a baseline speech-decoding RNN using data augmentation, domain adversarial training, and a hybrid Adam-to-SGD optimizer schedule, cutting phoneme error rate 26.3% below baseline (23.6% → 17.4%) and reaching baseline performance 1.8× faster.

---

## 2. EMG-to-Text Decoding with Recurrent and Attention-Based Architectures
*Co-authored with Yixin Wu, Skylar Tanartkit, and Mingxin Liu — UCLA EC ENGR C147A/C247A*

Compared recurrent and attention-based architectures for decoding keystrokes from wrist EMG signals. Ran the GRU family and the base Transformer as individual, controlled experiments; the bidirectional GRU was the strongest model in the study, cutting test character error rate nearly in half versus baseline (23.8% → 13.98%).
